Questions shop owners ask

Can I try it before paying?

Yes. Download it and use it free during the trial. If it is not right for your shop, you have lost nothing.

Will it work when the internet is down?

Yes. Both releases work offline. The Stable release needs no internet at all, and the Rolling release works online and offline.

Is it only for pharmacies?

No. Pharmacies, supermarkets, clothing shops, electronics shops and market stalls can all use it.

Can my staff use it?

Yes. Add users and roles from the Admin panel. Every sale and stock change is logged with the user who made it.

Is my data safe?

You can back up your data any time from the sidebar, and the Rolling release backs up to the cloud by default.

What if something goes wrong or I need a feature?

Open an issue on our GitHub page and we will look at it.
